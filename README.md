# 📖 编程词典 (Programming Dictionary)

一个专为零基础程序员打造的微信小程序，解决初学者看不懂英文代码和报错的痛点。

## ✨ 核心功能
- **多语言检索**：支持 HTML/CSS/JS/Python/Java 等词汇分类筛选。
- **模糊查询**：输入关键词即可快速定位单词。
- **代码示例**：每个单词附带实际代码用例，支持一键复制。
- **暗黑模式**：全局极客风主题切换，保护视力。
- **数据联动**：标记“已掌握”后，个人中心的学习进度条会实时更新。

## 🛠️ 技术栈
- **前端**：微信小程序原生开发 (WXML/WXSS/JS)
- **后端**：微信云开发 (云数据库、云函数)
- **核心逻辑**：Promise 并发分页拉取、本地缓存状态同步、云函数数据双向联动

## 🚀 本地运行
1. 克隆本仓库到本地。
2. 使用微信开发者工具导入项目文件夹。
3. 在 `app.js` 中填入你自己的云开发环境 ID。
4. 编译运行即可。
